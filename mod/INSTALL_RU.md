# Мод Map Exporter: установка

[English](INSTALL.md) · **Русский**

`Civ6MapExporter` — небольшой мод-скрипт. В начале каждого хода он выгружает текущую карту
в `Lua.log` Civilization VI, а оптимизатор читает её оттуда. Это точнее скриншотов и проще,
чем разбирать сохранения. Мод только **читает** карту: на геймплей и сейвы он не влияет.

> Мод необязателен: карту можно нарисовать вручную в редакторе. Но по-настоящему полезен
> инструмент именно с импортом реальной партии.

## 1. Скопировать мод в папку модов игры

Скопируй всю папку `mod/Civ6MapExporter` из репозитория сюда:

```text
%USERPROFILE%\Documents\My Games\Sid Meier's Civilization VI\Mods\Civ6MapExporter\
    Civ6MapExporter.modinfo
    MapExporter.lua
```

Если «Документы» синхронизируются через OneDrive, путь будет
`%USERPROFILE%\OneDrive\Documents\My Games\...` (или `OneDrive\Документы\...`).
Если папки `Mods` нет — создай её.

PowerShell, из корня репозитория:

```powershell
$docs = [Environment]::GetFolderPath("MyDocuments")
$mods = Join-Path $docs "My Games\Sid Meier's Civilization VI\Mods"
New-Item -ItemType Directory -Force $mods | Out-Null
Copy-Item -Recurse -Force mod\Civ6MapExporter $mods
```

## 2. Включить логирование Lua (один раз)

Открой файл настроек игры:

```text
%USERPROFILE%\Documents\My Games\Sid Meier's Civilization VI\AppOptions.txt
```

Найди строку и поставь `1` (если строки нет — добавь):

```text
EnableLuaDebugLibrary 1
```

Без этого игра может вообще не писать `Lua.log`.

## 3. Включить мод в игре

1. Запусти Civilization VI → **Дополнения → Моды**.
2. Отметь **Civ6 Optimizer - Map Exporter** и примени.
3. Начни новую партию или загрузи сохранение.

Мод выгружает карту сам: после закрытия экрана загрузки и в начале каждого твоего хода.

## 4. Загрузить карту в оптимизатор

Логи игра пишет в **AppData**, а не в «Документы»:

```text
%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VI\Logs\Lua.log
```

В оптимизаторе открой **📁 Данные** и выбери:

* **🔄 Из игры (live)** — сервер сам читает `Lua.log` по пути выше. Включи
  **авто-обновление**, и карта будет подтягиваться каждые 12 секунд, пока ты играешь.
* **⬇ Импорт из игры (Lua.log)** — выбрать файл вручную (например, лог с другого компьютера).

Что импортируется: террейн, особенности, холмы, реки, ресурсы, чудеса природы и света,
привлекательность, улучшения, твои районы и границы, названия и население городов, твои
поселенцы, цивилизация и лидер каждого игрока, города-государства, пантеон и верования.
Клетки других игроков помечаются как недоступные.

Каждый ход в лог дописывается новый дамп между `CIV6OPT|BEGIN` и `CIV6OPT|END`. Импорт
всегда берёт последний, поэтому один и тот же файл можно загружать повторно по ходу партии.

## Запасной способ — FireTuner, без мода

1. В `AppOptions.txt` поставь `EnableTuner 1`.
2. Запусти **FireTuner** (входит в *Sid Meier's Civilization VI Development Tools*: Steam → Библиотека → Инструменты).
3. Вставь содержимое `MapExporter.lua` в Lua-консоль и вызови `ExportMapForOptimizer()`.
4. Дальше — как в шаге 4.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| «Lua.log не найден» | Проверь шаг 2 и ищи файл в `%LOCALAPPDATA%`, а не в «Документах» |
| «В Lua.log нет строк CIV6OPT» | Мод не включён (шаг 3) или первый ход ещё не начался — заверши ход |
| Мода нет в списке | Папка лежит не там, или файлы оказались на уровень глубже |
| Карта «сдвинута», соседства неправильные | На твоём типе карты другая чётность offset-координат. См. `_offset_to_axial` в `backend/io/lualog_parser.py` и открой issue с куском `Lua.log` |
| Неизвестные типы террейна или особенностей | Они попадают в `warnings` импорта — открой issue с их названиями |
| Экспорт перестал работать после установки других модов | Некоторые моды-фреймворки (например, *Community Extension*) меняют порядок загрузки — попробуй отключить их для проверки |
